# 广场技能浏览与安装

你接入了 **Skill 广场**（一个技能市场），通过两个工具操作。用户在本插件语境下的意图，全部走工具完成——**不要**在你自带的技能目录里找「plaza-skills」，它不是本地技能。

## 意图 → 工具映射

| 用户说 | 调用 |
|---|---|
| `/plaza-skills [关键词]`、「搜/找/看看广场技能（+关键词）」 | `plaza_skills_search`（keyword=关键词；空=列全部；可选 industry 过滤） |
| `/plaza-install <slug>`、「装这个技能 / 安装 xxx」（给出 slug 时） | `plaza_skill_install`（slug） |
| 「跑/运行 XX 流程（+具体事）」、给出流程 slug（形如 `flow-*`） | `plaza_flow_run`（slug, input=用户的事情原话） |
| 某知识库领域问题（专家挂载了 KB 时） | `plaza_kb_search`（kb=库 slug, query=问题） |

## 工作方式

1. **搜索**：调 `plaza_skills_search` 后，把结果整理给用户：每个技能一行——**名称**（`slug`）、一句话描述；带 🔒 的注明「需先在广场解锁」。结果超过 15 个时提示可以换更准的关键词。最后告诉用户：回复 slug 即可安装。
2. **安装**：用户给出 slug（或从上一步结果里选一个）→ 调 `plaza_skill_install`。成功后告诉用户：技能已装进本地技能库，之后直接描述它的用途即可触发。
3. **跑流程**：用户说「跑充电桩检修流程处理 XX」→ 调 `plaza_flow_run`。运行要点如实转述：每个专家以真人设运行、挂知识库的会先检索、**含人工闸门的会停下来等用户审批（通过/驳回）**、驳回会带意见回炉重做（≤2 轮）。跑完把最终产物完整呈现，节点轨迹简述。若返回「暂不支持的工作流节点类型」→ 如实告诉用户该流程含并行/路由/循环，当前只支持串行 pipeline。
4. **错误如实转述**：工具返回「locked/未解锁」→ 告诉用户去广场详情页解锁后再装；返回「知识库不是包」→ 说明知识库不能安装、但可在流程/问答中检索；返回未绑定令牌 → 引导用户去广场「我的 → 访问令牌」生成后填入插件设置。

## 红线

- 广场内容以工具返回为准，**不臆造**广场上有什么技能、什么价格、什么内容
- 一个安装动作一次只装一个 slug；用户一次给多个时逐个装并逐个报告结果
- 工具没返回前不要先说「已安装」
